# Ongi

Claude와 GPT(Codex)의 **5시간·주간 사용량**과 채팅별 **프롬프트 캐시가 식기까지 남은 시간**을 Windows 작업표시줄에 작게 보여 주는 위젯입니다.

```
 ╭42╮  ╭77╮⁷˙⁰⁰
 ╰··╯  ╰··╯
 Claude GPT      ← 안쪽 액체 = 캐시 남은 정도, 10분 미만이면 오른쪽 위 배지 타이머
```

## 필요한 것

- Windows 10 또는 11. 필요한 .NET Framework 4.8은 기본으로 들어 있습니다.
- 다음 중 하나 이상이 같은 PC에 로그인되어 있어야 합니다.
  - Claude Code (Claude 구독 계정)
  - Codex (ChatGPT 계정)
- 로그인 정보가 아예 없는 서비스는 작업표시줄에 아이콘을 띄우지 않습니다. 나중에 로그인하면 다음 조회 때 나타납니다.

## 설치와 제거

받는 방법은 두 가지입니다. 빌드할 필요는 없습니다.

- **zip으로 받기:** [최신 릴리스](https://github.com/HoneyMocchi/Ongi/releases/latest)에서 `Ongi-<버전>.zip`을 받아 원하는 폴더에 풉니다. 예: `%LOCALAPPDATA%\Programs\Ongi`
- **git으로 받기:** 리포에 빌드된 `bin\Ongi.exe`가 들어 있습니다.
  ```
  git clone https://github.com/HoneyMocchi/Ongi
  ```
  업데이트할 때는 위젯 우클릭 → **종료** 후 `git pull`을 하고 다시 실행합니다. 실행 중에는 exe를 덮어쓸 수 없습니다.

1. `Ongi.exe`를 실행하면 시계 왼쪽에 위젯이 붙습니다.
   - 서명되지 않은 프로그램이라 처음 실행할 때 SmartScreen 경고가 뜰 수 있습니다. 이때는 "추가 정보 → 실행"을 누릅니다.
2. 부팅할 때 켜려면 위젯 우클릭 → 설정 → **Windows 시작 시 실행**을 켭니다.

### 업데이트

zip으로 받은 경우에는 설정 창 오른쪽 아래에서 업데이트합니다.
- 새 버전이 있으면 그 자리에 **`x.y.z로 업데이트`** 버튼이 나타납니다. 누르면 받아서 확인한 뒤 바꾸고 다시 켭니다.
- 새 버전이 제대로 켜지지 않으면 자동으로 이전 버전으로 되돌립니다.
- 설정은 그대로 남습니다.

git으로 받은 경우에는 버튼 대신 "git pull로 받기"가 표시됩니다.

제거하려면 다음 순서로 진행합니다.
1. 설정에서 **Windows 시작 시 실행**을 끕니다.
2. 위젯 우클릭 → **종료**를 누릅니다.
3. exe 폴더와 `%LOCALAPPDATA%\Ongi` 폴더를 지웁니다.

## 읽는 법

| 요소 | 뜻 |
| --- | --- |
| 모양 | 원은 Claude, 둥근 사각형은 GPT입니다. |
| 링 | 5시간 사용률입니다. 75% 이상이면 노랑, 90% 이상이면 빨강입니다. |
| 가운데 숫자 | 5시간 사용률(%)입니다. |
| 아래 점 5개 | 주간 사용률입니다. 점 1개가 20%입니다. |
| 안쪽 액체 | 가장 최근 대화의 프롬프트 캐시가 남은 정도입니다. 식을수록 수위가 내려가고 색이 초록 → 모래 → 산호로 바뀌어, 색으로 남은 분을 어림할 수 있습니다. |
| 안쪽 위 작은 점 | 캐시가 살아 있는 대화가 둘 이상일 때 대화 수입니다. 점 색은 각 대화의 남은 정도입니다. |
| 오른쪽 위 배지 | 캐시가 10분 미만이면 액체 대신 `4:30` 같은 남은 시간이 뜹니다. 한도가 다 찼으면 다시 쓸 수 있을 때까지 남은 시간이 빨간색으로 뜹니다. |
| 흐린 아이콘 | 조회에 실패해 값이 오래되었다는 뜻입니다. |

위젯을 **클릭**하면 상세 패널이 열립니다.
- 리셋 시각, 플랜, 채팅별 캐시 남은 시간이 나옵니다.
- **주간 페이스 막대**가 있습니다. 채움은 주간 사용량이고, ▼는 이번 주에서 지난 시간입니다. 이 둘을 비교해 여유 / 적정 / 과속 / 소진으로 알려 줍니다.

## 조작

- **클릭**: 상세 패널을 열고 닫습니다.
- **드래그**: 작업표시줄 안에서 좌우로 옮깁니다. 여러 모니터에 띄웠으면 옮긴 간격이 모든 모니터에 같이 적용됩니다.
- **우클릭**: 지금 새로고침 · 설정… · 위치 초기화 · 종료

설정은 바꾸는 즉시 적용됩니다.

| 항목 | 내용 |
| --- | --- |
| 위치 | 작업표시줄 / 떠 있는 창 |
| 아이콘 크기 | 작게(30px) / 보통(34px, 기본) / 크게(38px) |
| 모니터 | 작업표시줄 위치일 때 위젯을 띄울 모니터입니다. 주 모니터 / 모든 모니터 / 직접 선택(모니터별 스위치) 중에서 고릅니다. 모니터가 둘 이상일 때만 보입니다. |
| 표시 | Claude, GPT를 각각 켜고 끔 |
| Windows 시작 시 실행 | 부팅할 때 자동 실행 |
| 조회 주기 | 사용량을 다시 받아 오는 간격입니다. Claude는 요청 제한 때문에 최소 3분입니다. |
| 노랑·빨강 표시 | 경고색 기준(%) |
| 만료 알림 | 큰 캐시(기본 50만 토큰 이상)가 식기 몇 분 전(기본 5분)에 Windows 알림을 띄웁니다. |
| GPT 캐시 TTL | 화면 표시용 추정값입니다. 실제 캐시 유지 시간은 바뀌지 않습니다. |

## 프롬프트 캐시란

LLM은 턴마다 대화 전체를 다시 받습니다. 서버는 앞부분을 캐시로 재사용하는데, 이 캐시는 마지막 사용 후 TTL(Claude Code는 보통 1시간, GPT는 30분)이 지나면 사라집니다.

캐시가 식은 뒤 이어 쓰면 대화 전체를 다시 처리하므로 느리고 사용량이 더 듭니다. 큰 채팅을 이어서 쓸 계획이라면 식기 전에 메시지를 보내세요.

## 개인정보

- Claude Code와 Codex가 이 PC에 저장한 로그인 토큰을 **읽기만** 합니다. 토큰은 발급한 회사(Anthropic, OpenAI)의 사용량 조회 주소에만 보냅니다.
- 캐시 정보는 이 PC의 대화 기록 파일에서 시각과 토큰 수만 읽습니다.
- 다른 곳으로 보내는 데이터는 없습니다.
- 사용량 조회 주소는 공개 문서가 없는 내부 API라서, 형식이 바뀌면 조회가 실패할 수 있습니다. 실패하면 상세 패널에 원인이 표시됩니다.

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 아이콘에 `—`만 보임 | Claude Code나 Codex에 로그인되어 있는지 확인합니다. 패널을 열면 원인이 나옵니다. |
| 아이콘이 하나만 보임 | 다른 서비스의 로그인 정보가 없어서 숨긴 것입니다. 패널을 열면 원인이 나옵니다. |
| 다른 모니터에 안 보임 | 설정 → 모니터를 확인합니다. Windows 설정 → 작업 표시줄 → "모든 디스플레이에 작업 표시줄 표시"가 켜져 있어야 합니다. |
| "요청 제한(429)" | Claude 사용량 조회가 잠시 막힌 상태입니다. 5~30분 뒤 자동으로 다시 시도합니다. |
| 위젯이 안 보임 | 우클릭 → 위치 초기화를 누르거나, `Ongi.exe`를 한 번 더 실행합니다(실행 중이면 위젯을 다시 붙입니다). |
| 세로 작업표시줄 | 떠 있는 창으로 표시됩니다. |

설정·캐시·로그는 `%LOCALAPPDATA%\Ongi`에 있습니다. 설정 창의 "로그 폴더 열기"로 열 수 있습니다.
